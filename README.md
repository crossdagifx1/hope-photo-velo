## ✨ Project Overview

**HOPE Photo & Velo** is a world-class, modern digital platform engineered for a premier Addis Ababa photography and videography studio specializing in weddings, studio portraits, commercial campaigns, and fine-art albums.

The platform combines high-end editorial aesthetics with high-performance responsive engineering, seamless bilingual support (Amharic & English), interactive studio location maps, and instant booking workflows.

---

## 🚀 Key Architectural Features

### 1. 🌐 Seamless Dual-Language Engine (Bilingual)
- Built-in real-time language engine supporting **Amharic (አማርኛ)** and **English**.
- Zero layout shift during language transitions with centralized dynamic translation object `T`.

### 2. 🎨 Premium UI/UX & Dynamic Design Tokens
- Modern design typography using `Playfair Display` (serif titles), `DM Sans` (body), and `DM Mono` (accent tags).
- Custom CSS variable design system (`--paper`, `--cream`, `--red`, `--ink`) delivering dark luxury contrast and warm organic editorial feel.
- Fluid typography using CSS `clamp()` for flawless responsiveness across mobile, tablet, and ultra-wide desktops.

### 3. 🗺️ Interactive Studio Location & Google Maps Integration
- Direct interactive Google Maps embed preview showing **Tigat Building | Hayahulet | ትጋት ህንጻ | ሃያሁለት**, Addis Ababa.
- Dedicated 1-click Google Maps navigation routing button.

### 4. 📅 Instant Telegram & Phone Booking Workflow
- Direct phone dialing system integration (`+251910526962`).
- Integrated custom booking modal connected directly with Telegram consultation workflows.

### 5. 🖼️ Image Pipeline & Automated Watermark Processing
- Automated Node.js pixel-cropping pipeline built with `Jimp` to maintain pristine, high-resolution asset delivery across 30+ photo galleries without visual overlays.

## 💻 Local Development Setup

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/crossdagifx1/hope-photo-velo.git
   cd hope-photo-velo
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
